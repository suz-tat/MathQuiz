# MathQuiz (さんすう けいさん) - Web アプリケーション

Kotlin (Android / Jetpack Compose) で作成された算数学習アプリ「MathQuiz」を、HTML5 / CSS3 / JavaScript (Vanilla JS) でブラウザ向けに忠実に移植・再構築したWebアプリケーションです。

---

## 🌟 特徴と主な機能

1. **完全な出題ロジック移植 (`js/logic.js`)**:
   - 足し算（`+`）、引き算（`-`）、掛け算（`×`）の個別・複合出題
   - 数の大きさ（最大値 1〜99）の指定
   - 繰り上がり・繰り下がりの制御（「あり」「なし」「両方」）
   - 苦手問題優先出題ロジック（過去の履歴から設定条件に合致する問題を優先出題）
   - 同一セッション内での重複問題除外

2. **快適なクイズ体験 & 苦手克服 (`js/app.js`)**:
   - 見やすく操作しやすい専用テンキー（0〜9、消す/DEL、こたえる/OK）
   - PCキーボードからの入力（数字キー、テンキー、Backspace、Enter）に完全対応
   - 正誤の即時フィードバックと回答履歴（⭕/❌）の表示
   - **苦手判定タイマー**: 設定した基準秒数（デフォルト5秒）以上かかった問題は、正解・不正解問わず自動的に「苦手な問題」として記録
   - **苦手問題の自動消去**: 苦手リストから出題された問題を設定時間内に正解した場合、自動的にリストから卒業（削除）

3. **リッチな音声 & 演出 (`js/audio.js`)**:
   - **音声読み上げ (TTS) & 効果音 (Web Audio API)**: 問題式（例：「3 たす 5 は？」）や正解判定（「せいかい」）のクリアな読み上げ、ピンポン♫・ブブー・タップ音・キラリン✨ファンファーレを合成再生。右上のスピーカーアイコンからワンタップで一括ON/OFF（ミュート）が可能。
   - **紙吹雪 (Confetti) アニメーション**: クイズ終了時の達成感を高める演出

4. **データ永続化 & プライバシー配慮 (`js/storage.js`)**:
   - `localStorage` により、累計獲得メダル数、苦手な問題リスト、ユーザー設定をブラウザ内に安全に保存
   - **ストレージ利用同意バナー**: 初回訪問時に子ども・保護者へデータ保存の目的をわかりやすく提示する同意確認メッセージボックスを搭載
   - **クッキー・保存データの削除**: 設定画面からいつでも同意状態や保存データを完全初期化・削除可能

5. **多言語対応 (`js/l10n.js`)**:
   - ブラウザの言語環境に応じた自動言語切り替え（日本語 / 英語）に対応

6. **洗練されたレスポンシブデザイン (`css/style.css`)**:
   - Google Fonts (Zen Maru Gothic / M PLUS Rounded 1c) を採用した子供にも読みやすい丸ゴシック
   - スマホ縦向き、スマホ横向き（キーパッド横分割レイアウト）、タブレット、PC画面に完全対応

## 🚀 起動方法

### ブラウザで直接開く場合
`index.html` ファイルを Google Chrome, Edge, Safari などのブラウザでダブルクリックまたはドラッグ＆ドロップして開くだけで動作します。

### ローカルWebサーバーで動かす場合
```bash
# Python を使用する場合
python -m http.server 8080

# または Node.js を使用する場合
npx serve .
```
ブラウザで `http://localhost:8080` を開きます。
